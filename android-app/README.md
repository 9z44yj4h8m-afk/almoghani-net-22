# ALMOGHANI LIVE — Android APK

تطبيق Android يعرض صفحة https://almoghani-net-22.lovable.app/iptv.html مباشرة باستخدام WebView أصلي داخل التطبيق، ويفتح بالعرض تلقائيًا (sensorLandscape).

## المميزات
- RTL وتصميم الموقع نفسه.
- يفتح النسخة المنشورة من صفحة IPTV دون الاعتماد على نسخة مخبأة؛ تعديلات الصفحة تظهر عند فتحها دون تثبيت APK جديد، ولا توجد إعادة تحميل دورية تقطع البث.
- تشغيل الفيديو المباشر بكامل الشاشة، مع زر الرجوع للجهاز.
- استيراد ملفات M3U من لوحة التحكم عبر اختيار الملفات.
- تنزيل ملفات من روابط HTTPS وإشعارات نظام التنزيلات.
- طلب إذن الميكروفون والكاميرا عند طلب موقع المغني فقط.
- شاشة اتصال مع زر إعادة المحاولة.
- منع تجاوز أخطاء شهادات SSL.
- فتح الروابط الخارجية (مثل يوتيوب وواتساب) في تطبيقاتها.
- لا يتضمن كلمات مرور أو إعدادات اشتراكات ضمن ملفات التطبيق.

## طريقة إنتاج APK
من GitHub افتح **Actions → Android APK — ALMOGHANI LIVE → Run workflow**.
يمكن أيضًا إعادة البناء عند تغيير ملفات `android-app/`.

التنفيذ يستعمل Android Gradle Plugin 8.6.1 و Gradle 8.7 و Java 17 و Android SDK 35.
يمكن تنزيل APK من صفحة GitHub Releases أو من Artifact الخاص بالبناء الناجح.

## حدود النسخة الحالية
APK تجريبي `debug` موقّع بمفتاح اختبار يولده نظام البناء؛ لا يصلح للتوزيع عبر Google Play.
قد يتطلب إصدار APK جديد حذف النسخة السابقة ثم إعادة تثبيتها إذا تغيّر مفتاح التوقيع.
للنشر التجاري يجب استخدام مفتاح توقيع ثابت وسري مع بناء Release وتحديثات متوافقة.
التطبيق يحتاج الإنترنت، ولا ينزّل البث التلفزيوني للتشغيل دون اتصال.
