# ALMOGHANI LIVE — نسخة GitHub Pages

واجهة عربية داكنة (أسود وبنفسجي) للقنوات المباشرة والأفلام والمسلسلات، تعمل كصفحة ثابتة على GitHub Pages.

الرابط: https://9z44yj4h8m-afk.github.io/Z/

## ما في هذه النسخة

- الرئيسية: صفوف «بث مباشر» و«أفلام» و«مسلسلات» + بحث + أزرار الأقسام.
- البث المباشر: قائمة القنوات مع البحث والتصنيفات، والمشغّل داخل الصفحة (يوتيوب أو HLS).
- الأفلام والمسلسلات: تشغيل رسمي من يوتيوب.
- التواصل: واتساب والبريد وسناب شات وإكس.

## ما ليس فيها

GitHub Pages يقدّم ملفات ثابتة فقط، لذلك لا يوجد هنا: دخول أعضاء، مكتبة الاشتراك الخاصة، لوحة التحكم، الدردشة، أو الأصوات.
هذه تبقى على الموقع الرسمي: https://almoghani.net

## تحديث القنوات

قائمة القنوات تُقرأ من `https://almoghani.net/aa.m3u` عند كل تشغيل للـ GitHub Action
(`.github/workflows/channels.yml`)، وتُكتب في `channels.js` ثم تُرفع تلقائيًا إلى فرع `main`.
يعمل التحديث تلقائيًا كل ٦ ساعات، وعند كل دفع تغييرات، أو يدويًا من تبويب Actions ← "channels" ← Run workflow.

## تعديل التصميم

كل الصفحة في ملف واحد: `index.html` (التنسيق والسكربت والأفلام والمسلسلات وبيانات التواصل داخله).
بعد أي تعديل، ارفع الملف إلى فرع `main` وسيعيد GitHub Pages البناء تلقائيًا.
