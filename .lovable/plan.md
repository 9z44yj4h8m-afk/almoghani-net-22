# لوحة تحكم الموقع (للمالك فقط)

صفحة واحدة `/admin` يدخلها صاحب البريد a0552525337@gmail.com فقط بعد تسجيل الدخول. فيها خمسة أقسام بتبويبات:

## 1. القنوات
- قائمة بكل القنوات الحالية مع البحث، وزر لإظهار القناة أو إخفائها من الموقع.
- إضافة قناة جديدة: الاسم، القسم (إخبارية/رياضية/إسلامية/مسلسلات/أطفال/عامة)، رابط البث، الشعار.
- تعديل قسم أي قناة أو حذف القنوات المضافة من اللوحة.
- تُفحص الروابط الجديدة قبل الحفظ؛ الرابط الذي لا يعمل يُرفض مع رسالة واضحة، فلا تظهر روابط معطلة.

## 2. الأفلام المميزة
- إضافة فيلم بلصق رابط يوتيوب، مع العنوان والوصف.
- إخفاء أي فيلم من الصفحة أو حذف الأفلام المضافة من اللوحة.

## 3. الأعضاء
- قائمة الأعضاء: الاسم والبريد وتاريخ التسجيل وآخر دخول.
- إيقاف عضو أو إعادة تفعيله؛ العضو الموقوف لا يستطيع فتح المكتبة الخاصة.
- تغيير الرقم السري للمكتبة (حاليًا 0550)؛ الرقم الجديد يسري على الجميع فورًا.

## 4. نصوص الرئيسية والتواصل
- تعديل عنوان البنر (almoghani smarter) والسطر تحته (جميع القنوات) وعبارة Almoghani Smarter pro.
- تعديل واتساب والبريد وإضافة حسابات سناب وإكس وانستقرام؛ تظهر في صفحة التواصل والبنر.

## 5. التصميم
- اختيار اللون الرئيسي (البنفسجي) واللون الثانوي (السماوي) من منتقي ألوان مع معاينة.
- تغيير صورة الخلفية برفع صورة جديدة، وزر «إرجاع التصميم الأصلي».

## مواعيد البث
- لوحة المواعيد الحالية تنتقل لتصبح تبويبًا داخل نفس اللوحة.

## حدود واضحة
- اللوحة لا تغيّر ترتيب الصفحات أو تضيف صفحات جديدة؛ هذه التغييرات تبقى عبر الطلب هنا في المحادثة.
- روابط اشتراكك (مكتبة Smarters) لا تُدار من اللوحة لأنها مرتبطة بملف الاشتراك.

## التفاصيل التقنية
- جداول جديدة: `site_settings` (مفتاح/قيمة JSON للنصوص والتواصل والألوان والخلفية)، `custom_channels`، `channel_overrides` (إخفاء/نقل قنوات الكتالوج الثابت)، `custom_movies`، `hidden_movies`. قراءة عامة لما يلزم العرض، والكتابة لدور admin فقط عبر `has_role`.
- `profiles.suspended boolean default false`؛ سياسة قراءة للمشرف على profiles؛ `unlock_member_library` يرفض الموقوفين ويقرأ الرقم السري من جدول إعدادات خاص غير مقروء للعامة (افتراضي 0550).
- قائمة الأعضاء مع البريد عبر server function محمية تتحقق من دور admin ثم تقرأ البريد بصلاحية الخادم.
- كتالوج القنوات يُدمج على الخادم: `channels.ts` الثابت + المضاف − المخفي، ويستهلكه المشغّل والبحث والشات من مصدر واحد.
- فحص رابط البث في server function قبل الحفظ (استجابة HLS/يوتيوب صالحة).
- الألوان تُحقن كمتغيرات CSS في `__root` من الإعدادات؛ صورة الخلفية تُرفع إلى تخزين عام.
- `/schedule-admin` يتحول إلى تبويب ويُعاد توجيه الرابط القديم إلى `/admin`.
